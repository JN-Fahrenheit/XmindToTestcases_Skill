# XmindToTestCases 技能使用指南

## 1. 技能简介

`XmindToTestCases` 是一个自动化测试用例生成工具，旨在将符合特定结构的 `.xmind` 思维导图文件，快速转换为标准化的 Excel 测试用例文件。本技能通过预设的 Excel 模板，保留了样式和格式，极大地提高了测试用例的编写效率。

当用户发出“生成测试用例”等指令时，此技能将被触发。

## 2. 功能特性

- **自动化转换**：一键将 `.xmind` 文件转换为 `.xlsx` 格式的测试用例。
- **模板化输出**：基于预设的 `测试用例模板.xlsx` 文件生成用例，保留原有样式（如字体、列宽、颜色、合并单元格等）。
- **智能层级解析**：
  - 自动识别并处理 XMind 文件中的**多个画布 (Sheet)**。
  - 智能判断并处理**多个一级节点**（如“模块A测试”、“模块B测试”），确保所有模块的用例都能被完整解析。
  - 支持标准的**五级用例结构**，从模块到具体步骤，层层递进。
- **灵活的节点匹配**：通过关键字（`前提：`, `步骤：`, `预期：`）提取用例内容，即使关键字顺序不固定也能正确解析。
- **详细的错误提示**：在文件缺失、结构不符或关键字找不到时，提供清晰的命令行提示。

## 3. 目录结构

为了确保技能正常运行，请保持以下目录结构：

```
XmindToTestCases/
├── assert/                  # 存放输入的 .xmind 文件（自建）
│   └── your_test_cases.xmind
├── output/                  # 存放生成的 Excel 测试用例文件（脚本自动创建）
├── scripts/                 # 核心逻辑脚本
│   ├── main.py              # 主执行文件
│   └── requirements.txt     # Python 依赖
├── templates/               # 存放测试用例模板
│   └── 测试用例模板.xlsx
├── SKILL.md                 # 技能定义文件（供 Trae IDE 使用）
└── README.md                # 使用指南
```

## 4. 使用步骤

### 步骤一：安装依赖

首次使用前，请先安装必需的 Python 库：

```bash
pip install -r scripts/requirements.txt
```

> **提示**：仓库不包含第三方依赖包，依赖通过 `requirements.txt` 从 PyPI 安装（`openpyxl`、`xmindparser`）。如已安装可跳过此步骤。

### 步骤二：准备模板文件

1.  在 `templates/` 目录下，确保存在一个名为 `测试用例模板.xlsx` 的 Excel 文件。
2.  此模板文件的**第一行**必须包含以下表头（顺序可自定义）：
    - `用例名称`
    - `所属模块`
    - `标签`
    - `前置条件`
    - `备注`
    - `步骤描述`
    - `预期结果`
3.  您可以根据需要预设模板的样式（如字体、列宽、背景色等），生成的文件将完全保留这些样式。

### 步骤三：放置 Xmind 文件

将您需要转换的 `.xmind` 文件放入 `assert/` 目录下。脚本会自动查找并处理该目录下的第一个 `.xmind` 文件。

> **提示**：`assert/` 目录默认不随仓库发布（避免泄露业务数据），首次使用请自行创建，或直接解压仓库后新建 `assert/` 文件夹。

### 步骤四：执行转换

在 Trae IDE 或其他终端环境中，对我说“**生成测试用例**”，技能便会自动执行。

或者，您也可以通过手动执行脚本来完成转换：

```bash
python scripts/main.py
```

转换成功后，生成的 Excel 文件将保存在 `output/` 目录中，并以 `原文件名_测试用例_YYYYMMDD_HHMMSS.xlsx` 的格式命名。

## 5. 思维导图结构约定

为了确保脚本能够正确解析，您的 `.xmind` 文件**必须**遵循以下五级结构：

- **一级节点**: **模块/页面** (例如: *登录页面测试*)
  - **二级节点**: **测试类型** (例如: *功能测试*)
    - **三级节点**: **测试分类** (例如: *正向测试*)
      - **四级节点**: **具体测试场景标题** (这将成为 Excel 中的 **用例名称**)
        - **五级节点**: **详细测试用例**，这是一段包含特定关键字的文本，格式如下：
          ```
          前提：用户已登录系统。
          步骤：
          1. 点击“创建订单”按钮。
          2. 在表单中填写所有必填项。
          3. 点击“提交”按钮。
          预期：
          1. 提示“订单创建成功”。
          2. 页面跳转到订单详情页。
          3. 数据库中生成一条新的订单记录。
          ```

**注意**：
- `前提：`, `步骤：`, `预期：` 为必需的关键字，但顺序不限。
- `步骤` 和 `预期` 的内容如果有多条，建议使用换行或数字编号，脚本会自动将其拆分为多行，并与之一一对应。
- 如果第四级节点下没有第五级节点，该场景仍会被记录到 Excel 中，但相关步骤和预期列将标记为 `N/A`。
